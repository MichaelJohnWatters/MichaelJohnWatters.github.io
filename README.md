# personal-website-3js

Michael Watters' personal-branding site — a Three.js / React Three Fiber
experience deployed to [michaeljohnwatters.github.io](https://michaeljohnwatters.github.io).

## Develop

Requires **Node 20** (`nvm use 20`).

```bash
npm install     # first time only
npm run dev     # local dev server
npm run build   # production build -> dist/
npm run preview # preview the production build
```

## Deploy

Pushes to `main` auto-deploy via GitHub Actions → GitHub Pages. See
[`CLAUDE.md`](./CLAUDE.md) for full project notes.
